# 🧬 NEET Capsule – NEET Preparation Platform

**NEET Capsule** is a frontend-based web application designed to help **NEET aspirants** access study resources in a simple and organized way.

The goal of this project is to create a **clean, distraction-free learning platform** where students preparing for the **NEET (National Eligibility cum Entrance Test)** can quickly access important study material and preparation resources.

🌐 **Live Demo:**
https://neet-capsule.vercel.app/

---

## 🚀 Features

* 📚 Structured study resources for NEET preparation
* ⚡ Fast and responsive frontend interface
* 📱 Fully responsive design (mobile + desktop)
* 🎯 Clean UI focused on student productivity
* 🌐 Deployed online for easy access

---

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/neet-capsule.git
```

### 2️⃣ Navigate to Project Directory

```bash
cd neet-capsule
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Run the Development Server

```bash
npm run dev
```

Open your browser and go to:

```
http://localhost:3000
```
